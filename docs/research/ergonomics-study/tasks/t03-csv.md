# t03-csv

*Area:* CLI/text

Parse an embedded CSV document with a header row `name,dept,salary` and five data rows, one of which has a quoted name containing a comma (`"Cho, Jr."`). Sum salary per department and print `dept: total` sorted by department name. Expected: `Eng: 215000`, `Ops: 165000`, `Sales: 70000`. Also print `rows: 5`.
