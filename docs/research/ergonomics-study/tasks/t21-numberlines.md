# t21-numberlines

*Area:* files & I/O

Write a three-line text file `in.txt` (`alpha`, `beta`, `gamma`) into a temp directory, read it back line by line, write `out.txt` with each line prefixed by a right-aligned 3-wide line number and `: `, then print out.txt's content (`  1: alpha`, `  2: beta`, `  3: gamma`) and delete both files and the directory.
