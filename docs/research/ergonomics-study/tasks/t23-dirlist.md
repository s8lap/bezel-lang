# t23-dirlist

*Area:* files & I/O

Create a directory with files `b.txt` (3 bytes), `a.log` (10 bytes), `c.txt` (0 bytes). List the files sorted by name with sizes as `a.log 10`, `b.txt 3`, `c.txt 0`, then print the count of `.txt` files (`txt files: 2`), then delete the directory recursively and print `exists: False`.
