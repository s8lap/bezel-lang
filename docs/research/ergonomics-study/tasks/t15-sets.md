# t15-sets

*Area:* collections

Two tag lists: A = [web, api, db, cache], B = [db, queue, api, auth]. Print union, intersection and A-minus-B, each sorted alphabetically and comma-joined: `union: api,auth,cache,db,queue,web`, `both: api,db`, `onlyA: cache,web`. Also print whether {api,db} is a subset of A (`subset: True`).
