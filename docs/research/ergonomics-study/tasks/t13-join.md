# t13-join

*Area:* collections

Employees (name, deptId) and departments (id, name). Inner-join-ish: print `name -> deptName` for every employee in input order, `(none)` when the dept id is unknown. Then print per department the number of employees, including departments with zero (`Eng 2`, `Ops 1`, `Legal 0`). Data: depts 1 Eng, 2 Ops, 3 Legal; employees ann 1, bob 2, cho 1, dee 9.
