# t12-topn

*Area:* collections

Given players (name, score): (zed, 50), (amy, 70), (bob, 70), (cat, 40), (dan, 90). Print the top 3 as `rank. name score` ordered by score descending, then name ascending: `1. dan 90`, `2. amy 70`, `3. bob 70`. Then print the average score of all players to one decimal: `avg 64.0`.
