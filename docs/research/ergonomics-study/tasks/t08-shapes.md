# t08-shapes

*Area:* data modelling

Model shapes as a closed sum type: Circle(radius), Rect(width, height), Triangle(a, b, c) (Heron's formula). Compute each area, print `Circle 3.14`, `Rect 6.00`, `Triangle 6.00` (two decimals, in input order for shapes Circle(1), Rect(2,3), Triangle(3,4,5)), then the total area `total 15.14`, then the name of the largest shape `largest Rect` (first on ties).
