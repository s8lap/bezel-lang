# t09-weekday

*Area:* data modelling

An enum Weekday Monday..Sunday. Parse the strings `Monday`, `saturday`, `Funday` case-insensitively; for each print either `Monday weekend=False next=Tuesday` or `Funday: not a weekday`. Also print `Sunday next=Monday` (wrap-around) and the count of weekend days in the enum (`weekend days: 2`).
