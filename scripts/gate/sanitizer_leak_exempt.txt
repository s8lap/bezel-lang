# sanitizer_leak_exempt.txt — tests whose generated-code sanitizer LEAK
# report is a DELIBERATE assertion, not a defect (#4537).
#
# Read by scripts/gate/sanitizer.py. Format: one `suite.name` per line, with
# the reason after a `#`. Blank lines and full-line comments are ignored; a
# MISSING file is an empty set, so losing this file makes the gate stricter,
# never looser.
#
# THIS IS THE LEAK SIBLING OF sanitizer_exempt.txt, WITH A DIFFERENT
# RATIONALE — read that file first. sanitizer_exempt.txt declares rows whose
# CORRUPTION is undefined behaviour the spec itself allows; that reasoning
# does not apply here. Every row below deliberately ASSERTS that a real
# allocation escapes the compiler's release path — the test is checking for
# the ABSENCE of a fix, on purpose, because the underlying defect (e.g. a
# missing release site for a nested record/string field) is tracked by its
# own issue and not yet fixed. Under `--full` the deliberately-leaked
# allocation makes LeakSanitizer report at process exit, and the row PASSES
# because passing is exactly what "the leak is still there" looks like.
#
# WHAT BELONGS HERE — a row that POSITIVELY asserts a leak occurred (checks
# for the PRESENCE of "detected memory leaks" / `ERROR: LeakSanitizer` in the
# diagnostic text, or an `r.ran == false` outcome it explicitly attributes to
# a leak headline rather than a crash). If a row's leak is incidental (it
# would pass whether or not LSan happened to see the allocation) it does not
# belong here — fix the row instead, or drop it to sanitizer_exempt.txt if
# what it actually pins is a UB corruption crash.
#
# WHAT DOES NOT — a row asserting leak-FREEDOM (`find(...) == npos`,
# `ASSERT_FALSE(leaksAtLeast(...))`, `expectLeakFree`, `hasSanitizerReport`/
# `hasMemoryError` used with `EXPECT_FALSE`) never produces a report while
# passing, so it needs no declaration; and a row whose own runner redirects
# its subprocess output away entirely (`> /dev/null`, outside the standard
# aot_support.hpp harness) is structurally invisible to this channel and also
# needs none.
#
# A leak report in a FAILING test is never exempt (this file is consulted
# only for tests that PASSED), and a report from a test not listed here fails
# the cycle by name — same rule as sanitizer_exempt.txt, applied to leaks by
# scripts/gate/sanitizer.py's verdict().
#
# ── measured population (2026-09-21) ────────────────────────────────────────
# FIVE distinct deliberate-leak patterns were found, by (1) `grep -rlnE
# '"detected memory leaks"|"LSan/ASan at exit"|leak.*[Ss]anitizer|expectLeak|
# leaksAtLeast' tests/ --include=*.cpp` (71 candidate files), (2) reading each
# candidate's actual assertions to discard every NEGATIVE (leak-freedom) row,
# (3) confirming every survivor empirically against the already-built
# `bezel_tests_codegen` binary with `BEZEL_AOT_FORCE_SANITIZE=address
# BEZEL_TEST_FILTER=<suite>`, checking for `[san-scope] leave <name> pass`
# bracketing an `ERROR: LeakSanitizer` headline (not `ERROR: AddressSanitizer`
# — that is corruption, sanitizer_exempt.txt's list, not this one). All 37
# rows below were so confirmed. The four non-codegen candidate files
# (tests/module/xmod_auto_property_setter_arc_2490_test.cpp,
# tests/module/xmod_named_local_setter_arc_2505_test.cpp,
# tests/ownership/out_owned_discard_leak_1467_test.cpp,
# tests/sema/serialization_typedriven_703_test.cpp) were read and contain only
# leak-FREEDOM assertions or hand-rolled runners that redirect to /dev/null —
# no additions needed there.
#
# RESIDUAL RISK: this is a bounded, pattern-driven search, not a full `--full`
# sweep of the whole suite (a lane must not run that — CLAUDE.md). A row using
# a positive-leak-tolerance pattern not covered by the five below, or added
# after 2026-09-21, will not be caught by this file and will legitimately FAIL
# the next `--full` cycle by name; that failure IS the mechanism working
# (fail closed), and the fix is to add the row here with its reason, not to
# weaken the gate.
#
# (a) `leaksAtLeast(program, minBytes)` — 11 rows, 7 files. The floor-bytes
#     helper defined per-file; asserts `leaksAtLeast(...) == true`.
# (b) `expectLeakButNoMemoryError(r)` — 19 rows, 5 files. A shared-shape local
#     helper (defined once per file) that asserts `t.find("detected memory
#     leaks") != npos` AND excludes UAF/double-free/SEGV text.
# (c) `expectLeakNotCrash(prog)` — 4 rows, 1 file
#     (using_var_discard_vtableless_builtin_wild_jump_4224_test.cpp). Asserts
#     `r.ran == false`, a `sawLeakReport` flag set from a leak headline, and
#     the absence of every crash-signature string (SEGV/DEADLYSIGNAL/wild
#     jump/heap-buffer-overflow) — mirrors (d)'s inline shape as a helper.
# (d) An inline instance of (c)'s exact shape — 1 row
#     (plain_var_vtableless_builtin_discard_leak_4185_test.cpp), the control
#     row (c)'s file's own header comment says round 1's review asked for.
# (e) `diagnosticMessageContains(r, "LSan/ASan at exit")` — 2 rows, 2 files.
#
